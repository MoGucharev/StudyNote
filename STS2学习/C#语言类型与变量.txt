#类型
##double
-小数类型，占8字节，精确

##float
-小数类型，4字节，不精确
-要在赋值数字的末尾加上f
 eg：float a = 1.234f；

##List
-数量不固定的数组
-语法:List<T>，t为类型，如int

##decimal
-小数类型，16字节，极其精确
-在赋值数字末尾加m
 eg：decimal price = 1.234m；
-用来储存钱等敏感数字

##struct
-结构，和c中用法一致
-如果在初始化时赋值，则需要做一个显式构造函数来防止报错
eg：        public readonly struct structA
        {
            public readonly int num = 1;
            public structA()
            {

            }
        }
这个public structA()就是显式构造函数，它里面可以不放任何代码，只是让引擎使用

#概念
##引用类型，如string
-它不储存变量，而是指向一个已经存在的变量
-对此类型本身赋值，/注意是本身/，改变的是它指向的变量，并不会改变变量本身
-如果它指向一个包含其他变量的变量，比如类，通过它来改变此变量内部的变量，则会改变此变量的内部
 eg：a = player().new()；
     a.HP = 100; //此时为100
     b = a；
     b.HP = 50；  //此时为50
     CW(a.HP) //为50
