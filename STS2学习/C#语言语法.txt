#using
-类似于c的#include，导入命名空间
-调用方法前先调用using
-没有using也可以使用其他命名空间的函数，格式：命名空间.函数名
 eg：AAA.sayName()

#namespace
-类似gdscript的class_name，给对象命名
-语法namespace 名称 {}
-比class_name好用的一点是，可以在一个脚本内有多个nameplace。
-namespace不能直接运行脚本，必须在里面创建类，在类里才可以运行脚本
-相当于命名的文件夹，易于管理和查看，所以一般会用命名空间包括类
-可以不带花括号，表示之后的代码都属于此命名空间
-可以用.表示层级，不需要为原本不存在的父层级真的再创建一个层级

#class
-创建一个类，类中包含数据和方法。
-语法class 名称{}
-可以在命名空间外面建立class，但会变为全局函数

#foreach
-相当于gdscript的for
-用法foreach (元素类型 临时变量 in 集合)
{
    // 对每个元素做事情
}
注意要在变量前加变量类型

#Type和T
-Type是表达类型的类型，比如Type a = typeof(b)，a可以是int，node等
-T是表述任意类型的参数，T类型的变量可以为任何类型，比如T a，a可以是node变量，也可以是int变量，而且这里的a是变量本身，可以储存，和Type是类型本身不一样

#for
-与c的for更类似，按照数字开始循环，而不是将目标容器中的元素抽出来进行循环

#delegate
-委托，是储存函数的变量,创建后可以将函数当作变量来进行传递
-语法delegate 后加创建函数那一套
-可以用委托当作储存一堆函数的列表，来储存函数；也可以只把委托当作变量，用来当作参数
-创建的delegate，创建时命名需要在末尾加上EventHandler，在使用时，不需要加上EventHandler，只需要使用前方的名字就可以

#try,catch
-处理异常发生的代码，try里包含想要处理的方法，而catch里包含发生问题时要执行的代码
-语法：try{
}
catch{Exception
}catch的{}内可以填写仔细的异常错误

#internal
-表示在同一个程序集（即同一个项目）内部可以访问，不是同一个项目无法访问

#public
-只会管是否能找到的权限，如果函数调用不在一个类里，那么用public修饰也无法查到

#static
-C#中重要的概念，由于C#面向对象，所以非静态变量，方法需要实例化使用，静态变量，方法不需要

#protected
-表示只有自己和自己的子类才能访问，其余都无法访问

#attribute
-[Export]等这类标签的总称
-只是方便用户和编辑器编辑和查看，没有代码层面的作用

#readonly
-只读，在变量赋值后生效
-只会将指向的变量只读，如果指向变量内有其他变量，则可以修改，比如结构，类里面的变量可以修改
-（与godot有关）不能给引用节点的变量添加，因为函数构造的顺序先于节点树

#const
-只能让基本变量和字符串只读，且在赋值时就生效

#var
-用var作为变量前缀，可以不用声明变量的类型，让变量根据右半边数据的类型进行判断
-语法：var 变量名 = 数据；
 eg：var a = 1.2f; //为float变量
    var b = 1.234; //为double变量
-只能用在方法里，不能在类里使用

#new
-实例化类型或者类时用，比如List

#base
-调用父类型的方法，变量，构造函数等
-调用构造函数需要用:base()这种格式。调用方法base.方法名()
-调用构造函数时，编译器会根据你输入的变量来自动查找调用哪个构造函数

#IEnumberable
-如果只要求变量可以被foreach遍历，则用此类型
-语法：IEnumberable<T>
-里面的变量无法被修改，也无法增加删除变量
-占用内存最小，比list和HashSet都要小
-注意，使用时要求等号右边也是类数组，如果不是，则需要用[]将等号右边圈起来

#HashSet
-获得一个去重后的哈希值集合，此集合不属于List，Array等任何类型，使用时要To转换
-优点是可以拿来去重，且得到的数值省性能，缺点是得到的集合不具有任何查找能力，只有遍历能力

#KeyValuePair<>
-内部只有两个字段的类型，可以直接调出Key和Value

#IEnumberable<KeyValuePair<>>
-除了godot引擎的变量以外，C#语言中所有可以变量且有键和值的变量的基类都继承与它，所以可以用它来做未知字典类型的继承
-比如创建一个字典的查询方法，但是不知道字典的键和值类型，可以用此方法，在调用时输入类型，从而获得可以广泛使用的方法

#params
- 用在函数参数的最后一个参数那里，表示最后一个参数是一个数组
-语法：params string[] 数组名称 或者 params (string name,int count)[] 名称

#replace
-将字符串的旧内容换成新内容
-字符串的方法，需要在字符串后  .replace(旧内容，新内容)使用

#get
-在读取变量时执行，且只有一个get存在时，会让变量变为只读
-当存在set时，才会变为可写

#set
-在赋值时执行
-可以用来限制数值等

#global::
-从根命名空间开始寻找

#global using
-给所有文件都用上某个命名空间，不用每到一个就命名一次

#out
-把某个参数从“读取它在方法中使用”变为“把方法中的此参数结果读出来”
-有out的参数，在使用方法时也要加上out前缀
-可以用来让参数返回多个结果，比如参数中有hp，方法中也有hp，可以在参数hp前写out，使用时会把hp作为变量带出来，可以在之后的代码中使用

#record
-储存数据的一种类型，里面数据不可修改，但是可以用with复制一个新值并修改
-语法：public record 名称(类型 数据名，类型 数据名,.....)
-with语法：var 新变量名称 = 被复制变量名称 with {要改变的元素名称 = 改变后的变量}
-可以改写的record语法使其变为显性且可以修改，但是无法new创建新变量（需要自己写一个方法使其可以new创建新变量）

#abstract
-使用时和协议一样，只需要声明方法即可。因为是覆写的空白关键字，所以可以只写方法名。
-使用后，编译器会提醒子类必须写带有abstract关键字的方法
-有abstract的类无法实例化，但是如果基类是abstract，子类不是，则子类可以正常实例化

#异步
##async
-方法关键字，表示方法内可以使用await来进行异步流程
##Task
-一个类型，可以作为方法的返回值
-表示此方法可以在引用时被await
-Task<T>，T表示方法返回值类型，由于Task占据了返回值位置，所以有T来补充返回值
-内部具有很多用来查询异步调用的属性值

##用法
-一般async和Task会配套使用，Task提供了一套方法异步执行失败时的属性，可以防止崩溃
-如果只使用async 返回值为void，则异步执行失败时会报错

#线程
-Task.Run()来调用线程池中的线程，run后的()里需要是方法名称，即不带括号的方法
-Lock（）是锁，用它来让一个方法只被自己所调用，避免多线程同时调用导致紊乱。括号内是object类型，理解为锁的标志
其唯一作用是多线程调用时，告诉其他线程不能同时调用同一个，比如主线程在修改变量a，则后台线程必须等待主线程修改完，之后才能修改
锁内的代码随意换，因为锁本身不和代码绑定，只起到一个”告诉其他线程不能同时做某件事的“作用


#符号
##?
-建立新的属性，用法类似a.b = 1，只不过变成了a?b=1
-只是给编写的人和编译器一个提示，意思为这里的属性可能为null，没有判定或者其他作用
-在赋值变量时使用，意思是此变量可能为null，无实际作用
-与int的?不一样
## null！
-告诉编译器不用警告我这里是null
##=>
-等于 get{return....}
##?.
-如果？.左边是null，那么将不会执行右边
##!.
-告诉编辑器，保证左边一定不是null
##（）=>{}
-现场生成一个方法
-()里储存变量，{}里储存代码
-和gdscript的func():有点像
##int?
-让int可以等于null，也可以是int
-没有？的int无法为null
## ||
-逻辑或，左边为true时则不再执行右边，直接返回true
## ??
-左边为null，则直接返回右边的值。比如 null ?? false，执行时返回false
##:
-可以用:单独指定此数值传给方法里的哪个参数
##三元条件运算符
-即：？组成的运算符，只能拿来赋值，比如true时赋值为...，false时赋值为……
-除此之外，可以拿三元运算符来当反转使用，比如我想让一个一些情况时a>b，零一些情况时a<b，这时可以用参数当三元运算符的判断根基来实施转换。比如inverse: a>b? a<b，当inverse为true时，用第一个，为false时用第二个
##_=
-弃元符号，用在方法之前，表示此方法的返回值我不需要，类似信号的unbind()
-如_=acd()

##契约思想

之后使用时：需要在使用的class后方加上：契约名称，表示继承此契约，之后其他节点都可以调用此契约
-契约的使用思维和gdscript的判断谁会受到伤害的Hurtbox和HitBox有点像，说白了是自己在godot里用的逻辑习惯，在这里用代码规范表述起来

##属性与变量
-属性和变量长得很像，在表面上属性是变量＋{}，{}里用get或set来修饰
-属性是给外部调用的接口，用来读取对应变量或者限制修改对应变量
-在get和set加持下，属性的整体作用更像调用变量的public函数。
-属性的创建方法和变量一致，只不过在后面加了一个{}，{}里有get或set
-“=>”是创建属性的一种方法

##方法重载
-可以同时命名好几个相同名称的函数，但是参数需要不同
-调用时，编译器会根据你给的参数不同，从而调用不同的函数
-调用时如果给的参数比较少，则会调用参数有默认值的函数

##静态与非静态
-方法分为静态和非静态
-静态方法带有static，属于类的方法，可以直接调用，但无法调用实例数据，可以调用静态数据
-非静态方法不带static，属于对象的方法，调用时需要用new创建新的实例，可以调用实例数据，无法调用静态数据
-在根据对象创建变量时，非静态方法可以调取每个对象的数据，而静态方法可以获取类的值
-静态方法，变量都没有this，即对它自己属于哪个对象的认知，所以静态方法调用实例时需要先创建实例。而动态方法变量有this，已经相当于实例。二者不能混用
-一个类中，不能用一个实例变量去引用另一个实例变量，但是可以用一个实例变量去引用另一个静态变量

##类的继承
-如果一个类继承另一个类，则其可以使用另一个类的所有方法，且可以在此基础上加以添加方法
-和gdscript的脚本间的继承有点像
-用sealed关键字来限制此类，使其不能被继承
-继承的子类中，使用父类中的变量时必须要让父类中已有的关键字都一致，之后才可以添加新的，比如父类中又protected，而子类在覆写时
必须要写protected

##构造函数
-和类名一样的方法，但是无法返回值，无法被直接调用
-在子类继承或者创建此类的变量时可以使用
-更加规范，方便的赋值
-只读变量可以在构造函数里赋值一次
-普通类的构造函数，在new创建时，构造函数会自动执行；静态类的构造函数，会在类第一次被调用时执行

##[Flags],HasFlag
-二者一起使用，可以用来使一个伤害具有不同的性质，比如祭品，扣6点血，需要伤害有“无视护甲”“无法受到加成”“由卡牌造成的伤害”三个性质
-[Flags]用于枚举，且枚举里的变量必须为2的次方，比如1，2，4，8.....
-而|（按位或）比较二进制，如果有一个是1，则为1，且直接改变数值.HasFlag返回bool，语法为value.HasFlag(value2)，与按位与有关
等价于(value & value2) == value2
-原理在于2，4，8...在二进制里1的位置不同，通过按位或来使一个伤害类型，在指定的位数上有1；用按位与来检测指定伤害类型的位数是否为1.

##子类型继承
-如果想用父类型的变量，那么必须要用子类型自己的名字.变量来使用。不能像GdScript一样直接用。
-子类型和父类型在继承后，二者指向同一个堆，二者唯一的区别是父类型看不见子类的特有的变量等。在内存的创建过程中，二者的堆就已经创建完成，且是按照最多的那一方进行创建。
-需要new的类型本质是指针，指向堆内的内容。
-有几个对象取决于new了几次
-所以即使子类型只用属性的方法将父类型转换为子类型，不储存任何内容，但是转换后的父类型仍然可以当作子类型用，因为二者共用一个堆。
